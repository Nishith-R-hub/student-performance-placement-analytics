**Student Performance & Placement Analytics** | Python, Pandas, SQL, Power BI

## C) 3-Bullet Detailed Version

**Student Performance & Placement Analytics** | Python, Pandas, NumPy, SQL, Power BI, Data Visualization

- Built a complete data analytics pipeline: generated a synthetic 1,000-student dataset, performed data cleaning (handling ~4% missing values using median imputation), and conducted exploratory data analysis with 19 professional charts using Matplotlib and Seaborn.
- Executed 14 SQL queries on a SQLite database to analyze placement rates by branch, CGPA range, internship status, and backlog count; identified CGPA (r = 0.50) and backlog status as the strongest correlates of placement success.
- Designed a multi-page Power BI dashboard with KPI cards, interactive slicers, and custom DAX measures; documented findings in a GitHub-ready report with actionable recommendations for students, colleges, and placement coordinators.
